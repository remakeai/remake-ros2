# Security Implementation

## Authentication Methods

### 1. OAuth 2.0 (User Login)
Used for user authentication with the platform.

**Flow:**
```
1. User clicks "Login with Google"
2. Browser redirects to appstore OAuth endpoint
3. Appstore gets authorization code from OAuth provider
4. Appstore exchanges code for access token
5. JWT token returned to client
6. JWT stored securely in config
```

**Token Storage:**
- Linux/Mac: `~/.config/remake/config.json` (600 permissions)
- Windows: `%APPDATA%\Remake\config.json`
- File encrypted at rest (future enhancement)

**Token Refresh:**
- Access token expires in 1 hour
- Refresh token valid for 30 days
- Auto-refresh before expiration

### 2. HMAC-SHA256 (Robot Authentication)
Used for robot-to-platform authentication.

**Why HMAC?**
- Robot secret never transmitted
- Server can verify without storing plaintext
- Protects against man-in-the-middle
- Immune to password guessing

**Implementation:**
```python
import hmac
import hashlib

# Robot receives nonce from server
nonce = "server_nonce_abc123"

# Robot computes signature using its secret
robot_secret = "robot_secret_xyz"
signature = hmac.new(
    robot_secret.encode('utf-8'),
    nonce.encode('utf-8'),
    hashlib.sha256
).hexdigest()

# Send signature to server
# Server computes same signature and compares
```

**Verification (Server Side):**
```python
# Server stored robot secret in database
stored_secret = get_robot_secret(robot_id)

# Server computes expected signature
expected_sig = hmac.new(
    stored_secret.encode('utf-8'),
    nonce.encode('utf-8'),
    hashlib.sha256
).hexdigest()

# Use timing-safe comparison
is_valid = hmac.compare_digest(received_sig, expected_sig)
```

**Nonce Management:**
- Fresh nonce generated for each auth attempt
- Nonces expire after 5 minutes
- Database prevents nonce reuse
- Salt included in signature generation

## Asset File Security

### Path Traversal Prevention

**Attack Example:**
```bash
# Attempt to escape app directory
filename = "../../etc/passwd"
filename = "../../../home/user/.ssh/id_rsa"
```

**Defense:**
```python
def sanitize_path(filename: str) -> str:
    """Prevent directory traversal attacks."""
    # Remove path separators
    sanitized = filename.replace('\\', '/')

    # Remove traverse attempts
    sanitized = sanitized.replace('..', '')

    # Remove leading slashes
    sanitized = sanitized.lstrip('/')

    return sanitized

# Examples:
sanitize_path("../../etc/passwd") → "etcpasswd"
sanitize_path("../../../home/user") → "home/user"
sanitize_path("./normal/path") → "normal/path"
```

### File Isolation Per App

**Directory Structure:**
```
/assets/
├── app-001/
│   ├── model.pkl
│   ├── config.json
│   └── data/
│       └── training.bin
├── app-002/
│   ├── model.pkl
│   └── metadata.json
└── app-003/
    └── resources/
```

**Access Control:**
```python
def download_file(app_id: str, filename: str) -> bytes:
    # Sanitize path
    filename = sanitize_path(filename)

    # Construct full path
    app_dir = Path(f"/assets/{app_id}")
    file_path = app_dir / filename

    # Verify file is within app directory
    try:
        file_path.resolve().relative_to(app_dir.resolve())
    except ValueError:
        # File is outside app directory - REJECT
        raise PermissionError("File access denied")

    # Return file
    return file_path.read_bytes()
```

**Benefits:**
- App cannot access other app files
- App cannot access system files
- Attempted breakouts are blocked
- Clear audit trail of access

### File Integrity Verification

**SHA256 Hashing:**

    angular_z = max(-max_angular, min(max_angular, angular_z))

## Rate Limiting

### API Rate Limits

**Authentication Endpoints:**
- 5 attempts per minute per user
- 10 attempts per 5 minutes per IP
- Exponential backoff after failures

**App Launch:**
- 20 launches per 5 minutes per user
- Prevents launch spam
- Detects denial of service attacks

**General API:**
- 100 requests per 15 minutes per robot
- 50 requests per 15 minutes per user
- Sliding window algorithm

### Implementation
```python
from datetime import datetime, timedelta

class RateLimiter:
    def __init__(self, max_requests, window_sec):
        self.max_requests = max_requests
        self.window_sec = window_sec
        self.requests = []

    def is_allowed(self) -> bool:
        now = datetime.now()
        cutoff = now - timedelta(seconds=self.window_sec)

        # Remove old requests
        self.requests = [r for r in self.requests if r > cutoff]

        # Check limit
        if len(self.requests) >= self.max_requests:
            return False

        # Record request
        self.requests.append(now)
        return True
```
